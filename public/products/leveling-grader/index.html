Система автоматического нивелирования для грейдера

Модель: Система автоматического нивелирования для грейдера
Области применения:
Дорожное строительство Грейдирование Планировка Профилирование

Описание

Система автоматического нивелирования предназначена для повышения точности нивелировочных работ выполняемых грейдером. Система самостоятельно позиционирует отвал в соответствии с выставленным уровнем или загруженной целевой поверхностью, снижая тем самым требования к квалификации оператора и повышая точность и производительность.

Точная инерциальная система на основе трехосевого измерительного модуля и интегрированной ГНСС-технологии обеспечивает надежное 3D-позиционирование, стабилизируя углы наклона и корректируя положение рабочего органа в режиме реального времени. В результате достигается высокая точность по высоте, продольному и поперечному наклону.

Основной дисплей с высоким разрешением отображает ключевые параметры на одном экране: текущее положение, проектную поверхность и данные по уклонам и выемке/насыпи. Программное обеспечение системы предлагает интуитивный интерфейс для настройки режимов 2D и 3D, калибровки и контроля всех этапов нивелирования. Опционально можно подключить камеру для повышения безопасности работы на объекте.

Режимы работы

2D Нивелирование

Система оиентируется на данные с инерциальных модулей управляет наклоном отвала для получения заданного уклона дороги вне зависимости от положения грейдера и поворотного стола.

Оператор выбирает уклон, сторону управления.

Схема 2D

Применение:

  • Планировка площадок
  • Создание откосов с постоянным уклоном
  • Профилирование дорог по шаблону

3D Нивелирование

Режим 3D позволяет работать с трехмерной моделью площадки, отображая рельеф, проектную высоту и положение инструмента.

Система использует ГНСС и данные от инерциальных датчиков для точного определения положения машины и координат целевых точек, система сама позиционирует отвал по уровню и углу, выдает оператору подсказки повышая производительность.

Схема 3D

Применение:

  • Профилирование по сложным 3D проектам
  • Создание дорожного полотна с переменными уклонами
  • Работа с цифровыми моделями местности (DTM)

Преимущества системы

Точность

Система автоматического нивелирования обеспечивает профилирование с точностью до 1 см, используя двухантенную ГНСС-систему и инерциальные датчики для стабилизации отвала с отклонением не более ±1 см.
